# Interactive Sci-Fi Story

An interactive, text-based science fiction adventure built with Python and Streamlit.

The story allows players to explore different locations, interact with characters, make decisions and experience different outcomes based on their choices.

## Technologies
- Python
- Streamlit
- Google Gemini API

## Running the Project

1. Clone the repository.
2. Install the required dependencies:
   `pip install -r requirements.txt`
3. Create a `.env` file in the project directory and add your Gemini API key:
   `GEMINI_API_KEY=your_api_key`
4. Run the application:
   `streamlit run app.py`
